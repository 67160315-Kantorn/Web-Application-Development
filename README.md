# Granite Design Advisor — คู่มือรัน (สำหรับส่งให้อาจารย์ดู)

เว็บช่วยเลือกและออกแบบการตกแต่งบ้านด้วยหินแกรนิต มี frontend + backend + API จริง
รันในเครื่องได้ด้วยคำสั่งเดียว ไม่ต้องมี API key ก็ดูได้เกือบทุกฟีเจอร์

## ⚡ สรุปสั้นๆ ก่อนเริ่ม

- ✅ **ไม่จำเป็นต้องมี API key** ก็เปิดดูเว็บและใช้งานได้เกือบทุกส่วน
- 🔑 **มีแค่แท็บ "AI Chat" เท่านั้น** ที่ต้องมี Gemini API key ถึงจะใช้งานได้ (ถ้าไม่ตั้งค่า แท็บอื่นใช้ได้ปกติหมด แค่แท็บนี้จะขึ้นข้อความแจ้งเฉยๆ)
- 🔒 โปรเจกต์นี้**ไม่มี API key แนบมาด้วย** (ตั้งใจเอาออกแล้วเพื่อความปลอดภัย) ถ้าอยากทดสอบ AI Chat ด้วย ต้องขอคีย์ฟรีเอง — ดูวิธีด้านล่าง

---

## 🚀 วิธีรัน (ทำครั้งเดียว)

### สิ่งที่ต้องมีในเครื่องก่อน
- [Python](https://www.python.org/downloads/) เวอร์ชัน 3.9 ขึ้นไป (ตอนติดตั้ง ติ๊ก **"Add Python to PATH"** ด้วย)

### ขั้นตอน

เปิดโฟลเดอร์โปรเจกต์นี้ด้วย VS Code แล้วเปิด terminal (`` Ctrl+` ``) พิมพ์ทีละบรรทัด:

```powershell
cd backend
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
python -m venv venv
.\venv\Scripts\Activate.ps1
pip install -r requirements.txt
copy .env.example .env
```

> คำสั่ง `Set-ExecutionPolicy` จะถามยืนยัน ให้พิมพ์ `Y` แล้ว Enter (ทำครั้งเดียวพอ ปลอดภัย ไม่กระทบเครื่อง)

จากนั้นรัน server:

```powershell
uvicorn main:app --reload
```

รอจนเห็นบรรทัด:
```
Uvicorn running on http://127.0.0.1:8000
```

เปิดเบราว์เซอร์ไปที่ **http://127.0.0.1:8000** — เสร็จแล้ว 🎉

*(Mac/Linux ใช้คำสั่งเดียวกันหมด ยกเว้น `.\venv\Scripts\Activate.ps1` เปลี่ยนเป็น `source venv/bin/activate` และ `copy` เปลี่ยนเป็น `cp`)*

## 🔑 ถ้าอยากลองแท็บ AI Chat ด้วย (ไม่บังคับ)

1. ขอ API key ฟรีที่ https://aistudio.google.com/apikey (ล็อกอินด้วย Google account กด "Create API key")
2. เปิดไฟล์ `backend/.env` ด้วย notepad แก้บรรทัด `GEMINI_API_KEY=your-gemini-api-key-here` เป็นคีย์จริงที่ได้มา แล้วเซฟ
3. หยุด server (`Ctrl+C` ใน terminal) แล้วรัน `uvicorn main:app --reload` ใหม่อีกครั้ง (ต้อง restart ให้อ่านค่าใหม่)

## สิ่งที่ลองกดดูได้ในเว็บ

| แท็บ | ทำอะไรได้ |
|---|---|
| หน้าแรก | ดูตัวอย่างการตกแต่งแยกตามพื้นที่ (ครัว/ห้องน้ำ/ผนัง ฯลฯ) |
| แคตตาล็อกหิน | หินแกรนิต/หินอ่อน 24 ชนิด ข้อมูลจริงจากเว็บ siamtak.com กรองตามสี/สไตล์/พื้นที่ใช้งานได้ |
| เปรียบเทียบ | เลือกหิน 2–3 ชนิด เทียบเป็นตาราง |
| AI Design Advisor | ตอบคำถามสั้นๆ รับคำแนะนำหิน (ทำงานได้เลย ไม่ต้องใช้ API key) |
| AI Chat | คุยกับ Gemini จริงผ่าน backend (ต้องมี API key ตามขั้นตอนด้านบน) |
| คำนวณราคา | คำนวณราคาจริงจากข้อมูลในระบบ backend |
| โปรเจกต์ของฉัน | บันทึกหิน/ราคาที่สนใจไว้ดูภายหลัง |

## ปิดการใช้งาน

พอดูเสร็จแล้ว กด `Ctrl+C` ใน terminal ที่รัน `uvicorn` อยู่เพื่อหยุด server
